\# Corpus Callosum MRI Segmentation



\## Project Overview

This project focuses on preprocessing and segmentation of infant brain MRI scans using image processing and deep learning techniques.



\## Pipeline

1\. N4 Bias Correction

2\. Skull Stripping

3\. Intensity Normalization

4\. Sagittal Slice Extraction

5\. BM3D Denoising

6\. Super Resolution

7\. Segmentation



\## Technologies

\- Python

\- OpenCV

\- BM3D

\- NumPy

\- Deep Learning (U-Net)
